COMPATIBILITY

For Windows 10 and Windows 11 only. Player profiles are available for YouTube, VLC, Windows Media Player, and General / Browser media.

START THE APP

Open HandGestureVideoController.exe from the downloaded folder. No installer is required. Keep the downloaded folder together, including its _internal folder, and do not move the EXE by itself. If Windows shows a security prompt, choose More info and Run anyway only if you trust the copy you downloaded.

Allow camera access when Windows asks. In the app, select your camera and press Start camera. To stop gesture actions temporarily, press Pause App. Close the app with its normal window close button.

MEDIA GESTURES

Show one hand clearly to the camera and return to a relaxed or open pose between gestures.

Open palm: Play or pause.
Right-hand thumb and index pinch circle: Increase screen brightness.
Left-hand thumb and index pinch circle: Decrease screen brightness.
Thumb up: Increase Windows master volume.
Thumb down: Decrease Windows master volume.
Thumb pointing right: Seek forward.
Thumb pointing left: Seek backward.

SUPPORTED MEDIA

Choose the matching profile from Player profile, then press Apply profile:
- YouTube (in a supported web browser)
- VLC Media Player
- Windows Media Player
- General / Browser for other media that responds to Windows media keys or configured shortcuts

Keep the player or browser open and ready while controlling it. Controls and shortcuts may vary by player version. Volume gestures change Windows master volume for the whole computer.

HAND MOUSE

Turn on Enable hand mouse to use the left hand as a mouse pointer. Move the left index fingertip to move the pointer.

- Pinch thumb and index, then release, to click. Pinch again quickly to double-click.
- Pinch thumb and middle finger for a right-click.
- Pinch thumb and pinky twice, releasing between pinches, to toggle mouse mode by gesture.
- Optional dwell click clicks after the pointer stays still for the selected time.
- Adjust mouse sensitivity, smoothing, stability, target assist, or camera-area calibration in the app controls.

Mouse mode tracks one hand at a time. Turn it off to return to regular media gesture control. Use Pause App to stop gesture actions immediately.

OTHER CONTROLS

- Use the camera menu to select a webcam.
- You may use a compatible Android phone as the camera through Windows 11's connected-camera feature. Link the phone with Link to Windows / Phone Link, then on the PC open Settings > Bluetooth & devices > Mobile devices, select the phone, and turn on Use as connected camera. If Windows lists the phone camera, select it in the app's camera menu. This requires a supported Android phone and Windows 11; it is not available on Windows 10. Microsoft's instructions: https://support.microsoft.com/en-us/windows/apps/phonelink/use-your-mobile-device-s-camera
- Optional camera effects include background blur and person tracking.
- Adjust Hold Threshold to change how long a gesture must be held before it triggers.
- Enable continuous volume, seeking, or brightness while holding the matching gesture, then adjust the repeat speed.
- Use Apply keys to apply the play/pause and seek shortcuts shown in the app.
- Choose English or Arabic from the language selector.

NOTES

- Brightness control depends on support from your display and Windows driver. Some screens do not allow apps to change brightness.
- Target assist works with Windows controls that expose accessibility information; some games and custom-drawn content may not support it.
- If the camera or a gesture does not work, check Windows camera permission, close other apps using the webcam, improve lighting, and make sure the selected player is active.
